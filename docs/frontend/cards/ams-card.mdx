# AMS card

## Description

The AMS Card shows the information about your AMS devices

## Configuration

All configuration should be done via the dashboard card editor. The configuration options available are:

- Card Title
- Custom Sensors
- AMS Selection
- Card Style
- Show/Hide Types

## Vector Card

![Vector ams card](/images/cards/vector-ams-card.png)

- Shows dynamic spool volume remaining if enabled in the slicer, and is a Bambu Filament
  - If there is an MQTT issue where the filament remaining value is not reported correctly, the card will show a full spool
- Active spool can be identified by the highlighted border and animation

## AMS 3H

The H3C's AMS 3H uses the same card. It always uses the vector style, since there is no AMS 3H artwork for the graphic style.

- Its nine spools are shown in two rows, with five spools in the first row and four in the second.
- The AMS 3H has no single humidity or temperature reading. Instead, the info bar shows each drying zone's humidity, temperature and, while the zone is drying, the time left. Hover over a zone to see which trays it holds, and tap a reading to open its history.
- The card editor offers a custom remaining sensor for each of the nine trays.

The zone readings come from the AMS 3H's zone sensors (Zone *n* temperature, humidity and remaining drying time). Each one has `zone` (1-based), `zone_id` (the printer's 0-based id) and `slots` (the 1-based tray numbers in the zone) attributes.
