For configuration, you'll ideally use your Bambu Credentials for the simplest setup and the most features as some sensors are supported by data from your Bambu cloud account print history.
You can also, optionally, provide the printer's local IP address to enable the more efficient and reliable direct to printer connection for the printer sensor data and to enable the P1/A1 chamber image support.

However, the Bambu cloud connection doesn't support passwordless social media accounts at this time. And it obviously does not support printers explicitly set to Lan Only Mode.

Accounts with two factor authentication are supported. Bambu's 2FA endpoint is currently rejecting requests from the integration, so if your authenticator code is refused a verification code is sent to your email or phone instead - enter that when prompted.

### Configuring a Printer

1. Navigate to your Home Assistant's 'Settings' page (available in the sidebar).
2. Open 'Devices & Services' (second item in the list).
3. Click the 'Add Integration' button (typically in the bottom right).
4. In the pop up search for 'Bambu Lab' and select.
6. Follow the steps as prompted in the wizard.

### LAN Mode Setup

If you fall into any of these categories, select the Lan Mode Configuration connection option. You will need to manually provide:

- Printer Serial Number - can be found in the printer settings or in Bambu Studio.
- Local printer IP address - can be found in the printer network settings (LAN).
- Access Code - can be found in the Printer settings.

The serial number is in the form `a1b2c3d4e5f6a1b2`, not the `3DP-000-000` identifier shown for the printers name. 

Additional setup may be needed for specific entities to work:

- Camera feeds for H2D / H2S / X2D - you must enable the "LAN Only Liveview" option in the LAN mode settings. It is not necessary to enable LAN mode generally to enable the "LAN Only Liveview" option. This simply enables the RTSP stream to be available locally. The camera feed will also continue to work via Bambu Studio / Bamby Handy remotely.
- Cover image, Print weight, Print Bed Type - with newer firmware/printers (e.g. H2D 01.03.00.00, H2S 01.02.00.00, P2S), you must enable "Store Sent Files on External Storage" in the printer's "Print Options" settings, and use a USB drive/SD card (depending on the printer). These entities need to get the print file from the printer, but the internal storage doesn't seem to be exposed.

To add account-level MakerWorld sensors, add another Bambu Lab integration entry and choose **MakerWorld account**. This option is available only when an existing printer entry has working Bambu Cloud credentials. The MakerWorld entry reuses those credentials and can be reconfigured to use another working printer entry for the same account.

#### Advanced options

Advanced options should only be used for non-standard setup.

- Disable SSL verification - disabled certificate verification for MQTT, FTP and chamber camera connections to printer (unsafe).
- Enable filament inventory - exposes a sensor with your account-level Bambu Filament Manager spool data. Requires Bambu Cloud authentication. Default: disabled.
- Filament inventory refresh interval (minutes) - how often to poll the Bambu Cloud for updated inventory data. Default: 60 minutes.

### Setup using Bambu Cloud w/ OAuth

If you signed up using any OAuth method, you need to set a password for your Bambu Cloud account:

- Login to the Bambu mobile app using OAuth.
- Tap the person icon at the bottom right.
- Tap Account Security > Change Password.

This will allow you to set a password. Now you can login to the HA integration using your Bambu username and password
instead of OAuth.

### OrcaSlicer custom filaments (Orca Cloud)

The integration shows the names and temperatures of your custom filament presets by reading them from your slicer's cloud account. OrcaSlicer now syncs presets to its own Orca Cloud instead of Bambu Cloud, so if you slice with OrcaSlicer, link Orca Cloud as well. This works with any connection mode, including LAN mode.

1. Go to the integration, choose **Configure** on the printer, then pick **Orca Cloud filament profiles (OrcaSlicer)**.
2. Choose the account you sign in to OrcaSlicer with (Google, GitHub, Apple or Facebook).
3. Open the sign-in link and sign in. Your browser then tries to open `http://localhost:41172/callback?code=...` and shows an error such as "This site can't be reached". That is expected.
4. Copy the whole address from the browser's address bar and paste it into Home Assistant.

Home Assistant only reads your presets and never changes them. If a preset exists in both Bambu Cloud and Orca Cloud, the Orca Cloud copy is used. Presets are read each time the printer connects. Each printer is linked separately. To disconnect, open the same option and choose **Unlink Orca Cloud from this printer**.
