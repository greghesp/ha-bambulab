# HACS

The easiest way to install this integration, is to use [HACS](https://www.hacs.xyz/)

## Automatic Install
Once hacs is installed, simple click the button below to start the automated installation

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=greghesp&repository=ha-bambulab&category=Integration)

## Via HACS

ha-bambulab is a default repository within HACS. If you do not wish to use the automatic install, search for `Bambu Lab` within the HACS interface and download it.

## After installing

Restart Home Assistant, then [set up the integration](/setup).

The dashboard cards are included with the integration, so you don't need to install them separately. See [Frontend](/frontend).
